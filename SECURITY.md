# Sécurité

Pour un problème de sécurité propre à cette adaptation, contacte en privé le propriétaire du dépôt. Indique la version concernée et les conditions dans lesquelles le problème apparaît. Garde les clés ADB et les données personnelles hors du rapport.

Pour un problème du projet officiel, suis sa [politique de sécurité](https://github.com/Gathin23/cleanyourtv/blob/main/SECURITY.md).
